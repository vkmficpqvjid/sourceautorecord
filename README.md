## Overview

SourceAutoRecord (SAR) is the standard speedrun plugin for Portal 2, Portal, Half-Life 2, and other Source engine titles, providing in-game timer display synchronized to the authoritative demo timer, automatic demo recording on map load, checkpoint route comparison, and a complete suite of TAS (Tool-Assisted Speedrun) utilities including save-state simulation.

Whether you're a newcomer just getting started or a seasoned pro looking for advanced tools, **SourceAutoRecord** delivers the features you need in a clean, intuitive package.

> Official website: [sar.portal2.sr](https://sar.portal2.sr)

## Key Features

| Feature | Description |
|---------|-------------|
| **Accurate In-Game Timer** | Demo-synchronized timer display for portal and Source speedrunning |
| **Auto Demo Record** | Automatically records demos on each map load for review and submission |
| **Route Checkpoints** | Split-based checkpoint system for comparing routes and improving times |
| **TAS Utilities** | Save states, frame advance, and replay tools for TAS creation |
